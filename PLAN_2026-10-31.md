Decisions taken 2026-10-31 (owner: "choose from the data or from first principles"):
- Twin list roles (source + members, target + targets both filled): one role per legend question in the world, holding one or
  several shapes (the cause is our world design: two roles for one question). Measured against fix_p80_s0.
- Scoring: an action the editor executes the same way whichever order its two shapes come in (disconnect removes the link in both
  directions) is scored without order, for both readers; derived from docs/js/logic.js, not a list.
- Step 2: a second pre-registered run with the phases keyed by the centre's event token (the faithful port of B's E3d; the first
  run had one table for all 44 event tokens).
- Verbless requests: the legend rule (inherit, unique frame, else ask) is kept for the centre reader: 0.5% wrong, the rest asks,
  which is the editor's honest behaviour; built after the centre reader works.

Not in the plan (deliberately): the tagger; hand-written word lists; tuning anything on the test set.
