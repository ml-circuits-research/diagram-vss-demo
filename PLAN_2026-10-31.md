| what | number | source |

Where VSS loses, reading alone (ERROR_ANALYSIS.md): role wrong, mostly lists 8.4; no action word found 8.2; role missed 7.2; wrong
action or type 6.5; name not reachable 4.1; value not reachable 2.2; description read differently 1.6; status no-sense 0.8.
Where VSS loses when it cuts by itself: action words in the text outside the spans become requests (false centres), and some action
words are not recognized (requests merge). The reader has never seen text that is not a request.

What is settled: the pipeline is learned from the annotated messages (no hand tables); one labelling convention, labels corrected;
the tagger is out of the pipeline; thresholds calibrated on unseen rows; lists read as set roles.

## Plan (one step at a time; each step: hypothesis, measure, success criterion fixed first; then a root-cause analysis)

Roles: I coordinate and review; Opus agents implement; Sonnet agents write data. Nothing goes into the pipeline without a measurement
on dev; the test set is used once, at the end (step 6).
