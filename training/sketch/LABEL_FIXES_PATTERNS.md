## Rules applied

- P1: a `connect` whose span says `line` / `lines` (lower case word) and not `arrow` gets `arrow: "none"` (the editor's cue list maps `line` to none, logic.js:561). Inserted after `style` (before `color` / `label` if present). Spans with `arrow` (plain arrow, or their own `arrow` value) and wires that already had an `arrow` key were not touched.
- P2: a question whose span says `next to` ("Which shapes are next to X", "What is next to X", "Show what is next to X", "What sits next to X") -> `{ask: list, position: near, anchor: X}` (the legend lists `next to`, `near`, `beside` as cues of position=near; `neighbors` has the cue "what is connected to"). Span and trigger (`next to`) unchanged.
- P3: `mention(quantifier=all,recency=newest)` (the editor ignores recency when quantifier=all, so it matched every shape) -> `$new` (the value of the latest create / duplicate wire of the message, i.e. exactly the new copies); inside a list the other names stay (`Sensor,$new`). Only written when the copies were made by a duplicate wire earlier in the same message (asserted by the script).
