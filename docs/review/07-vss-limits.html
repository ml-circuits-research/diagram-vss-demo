07 / representation

A wrong final frame does not tell us which VSS step caused it.

The useful engineering question is where the intended argument was first lost or changed: input preparation, target conversion, vector prediction or SOP assembly.

Isolate the world on faithful inputs and targets before attributing errors to vector capacity.

Trace one failed reading all the way through

Move Box 20 px right of Dot.

Faithful SOP frame:

@c1 command action=move target=Box position=rightOf anchor=Dot distance=20

Suppose the final frame contains the wrong distance. There are at least three different causes. The training converter may have removed distance from the target. The front may have normalized the input incorrectly. Or the world may have received correct input and supervision but predicted the wrong role value. These cases require different fixes. Increasing vector dimension is not a repair for a target that never contained 20.

The shipped composer first cuts the message and selects candidate worlds. Each world’s front replaces recognized expressions with canonical event/value tokens and identifies names and numbers. The world assigns kinds, routes and binds word vectors, sums them into a state and decodes an action and roles. The adapter then writes the SOP nodes. The complete path also has context filling and confidence decisions. A single final success percentage combines all of these decisions.

For the technology sought here, the boundary to inspect is the semantic frame before context filling invents or chooses any concrete object. “Dot” is an explicit anchor in this example. A pronoun in a different request can remain a reference for the symbolic consumer. The world should be judged on preserving that distinction, not on solving the drawing context.

Specific early losses already exist

The inspected shapes front maps wide to rectangle. A training association between wide panels and rectangles does not establish that “wide” means rectangle: a wide ellipse is still an ellipse. If this normalization overwrites a distinction before vector composition, later decoding cannot be expected to reconstruct the original meaning reliably.

The same shipped front has gaps for bare “right of” / “left of”, number words such as two/three/four, and fill/layer values. These are inspections of front.json, not failure rates for every sentence containing those expressions. They identify concrete data/preparation questions that should be settled before calling the vector algebra inadequate.

The VSS loss rewards similarity between a composed vector and a target vector. The symbolic consumer needs the correct action, roles and literals. A slightly better cosine can leave the winning role values unchanged, or a small margin change can flip one crucial target. The old epochs experiment moved fit from 65.3% to 67.4% and reported about 16.5% front/context losses. It does not prove the current nine-world system has reached a fundamental capacity limit.

Relevant implementation: routebook.js, reader.js and the trainer.

The experiment that would answer the capacity question

First establish a set of real messages whose intended frames survive target conversion. Supply the correct request boundaries and world so the experiment isolates that world. Preserve explicit names, numbers and reference text; do not make the oracle solve pronouns as an extra requirement. Score the emitted frame with the repaired semantic comparison.

Then restore the actual cut/router and attribute the additional losses to the first failing step. Only the remaining errors of the isolated world are candidates for an experiment on dimension, routing, objective or decoder. Change one variable, refit confidence consistently and compare faithful frames at the same rate of confident false frames. Training cosine is a diagnostic alongside that result.

A failed run can show that a particular implementation and schedule failed. It does not show that no VSS representation can solve the bounded task. Conversely, a high fit score does not justify suppressing unresolved or unread portions. The reader’s contract remains explicit, faithful partial formalization.
